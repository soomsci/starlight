# 작은 과학실 · 빛은 어떻게 퍼질까?

중학교 2학년을 위한 빛의 거리 역제곱 법칙 시뮬레이션입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 빌드나 설치가 필요하지 않습니다. 인터넷이 없어도 작동하며, 온라인에서는 Google Fonts를 불러옵니다.

## 수업에서 사용하기

1. 1 m에서 구의 크기와 같은 면적이 받는 빛을 관찰합니다.
2. 2배 버튼을 눌러 구의 표면적이 4배, 빛의 세기가 1/4이 되는지 비교합니다.
3. 3배와 4배에서 결과를 예측한 뒤 슬라이더와 그래프로 확인합니다.
4. 일시정지하여 같은 방향의 빛 묶음이 덮는 구면 영역을 비교합니다.

## 모형의 의미

모든 방향으로 일정하게 빛을 내는 점광원을 가정합니다. 빛의 흡수와 산란이 없을 때 전체 광속 Φ는 보존되며 구의 표면적은 `4πr²`입니다. 구면의 단위면적당 광속은 `Φ / (4πr²)`이므로 1 m 기준 상대 세기는 `1/r²`입니다. 여기서 화면의 ‘빛의 세기’는 단위면적당 받는 빛의 양을 뜻하며 광원의 광도와 구분됩니다.

황금색 빛 묶음은 일정한 입체각을 나타내며, 이 묶음이 덮는 구면의 면적도 거리의 제곱에 비례합니다. 구면은 관찰을 위한 가상의 면이며 빛을 막지 않습니다. 광선과 점은 밀도를 설명하는 시각적 모형으로, 실제 광자 수나 속도를 재현하지 않습니다. 아래 1 m² 비교는 빛의 진행 방향에 수직인 작은 면적에서의 국소적인 세기를 대표합니다.

키보드로 거리 슬라이더와 버튼을 조작할 수 있습니다. 기기의 움직임 줄이기 설정이 켜져 있으면 애니메이션이 정지된 상태로 시작합니다.

## 파일

- `index.html`: 한국어 수업 화면
- `style.css`: 반응형 레이아웃
- `app.js`: 구면 및 광선 시각화, 거리 조절, 밀도 비교와 그래프
